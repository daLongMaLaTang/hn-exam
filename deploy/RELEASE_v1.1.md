# v1.1（构建版本 1.1.0）

本版包含连续填空“仅本次部分给分”，以及首次登录／密码重置后的修改密码页反复加载修复。

- 尚需改密码的学员不显示通知入口、不请求通知；即使收到 PASSWORD_CHANGE_REQUIRED，位于 /account 时也不重新加载自身。
- 改密成功后恢复通知，保留后端强制改密校验。
- 页面底部显示 v1.1，/version.json 提供公开版本信息。
- 无新增数据库迁移，不改变用户密码、答案或评分。

验证：前端 13 项测试、类型检查及构建通过；后端 193 项测试中 192 通过、1 跳过，生产 JAR 构建成功。浏览器隔离接口验证改密页仅加载一次，改密前通知请求为 0，改密后恢复为 1。

发布沿用 deploy/baota/README.md。后端包为 backend/target/hn-exam-1.1.0.jar，前端为 frontend/dist。先检查无进行中答卷并备份线上数据库与静态资源，再切换发布；保留旧哈希资源以兼容已打开的页面。正式数据以服务器为准。

服务器凭据仅保存在本机 .local/credentials/hqhexam-ssh.dpapi，使用 Windows 当前用户加密，目录 ACL 限制当前用户及 SYSTEM。不得提交或复制到公开附件。
