# 连续填空仅本次部分给分

在“成绩与人工判卷”的集中阅卷区，连续空答案组可选择“仅本次部分给分”。

1. 系统按参考答案匹配后展示各答案；已判对或已判错的空只读。
2. 勾选待判项中正确的答案，未勾选的待判项判错。相同文本出现多次时分别计数，连续空仍允许乱序。
3. 核对正确空数、预计本题得分、影响人数，再确认保存。存在组外待判空时，展示已确定正确空的折算分，并提示最终得分尚未确定。
4. 操作仅应用于当前答案组所列的本场作答，不加入长期答案库，不自动公布成绩。整题按正确空数比例四舍五入计整数分。

部分判定在同一事务中保存，每个待判空各有一条判定记录，可逐条撤销；已公布答卷撤销评分时仍需要明确撤回成绩。系统已识别的正确空不会被覆盖。人数或判定状态变化时，旧请求被拒绝，需要刷新核对。

该功能复用现有逐空评分及判定记录表，不需要新增数据库字段。部署时同时更新后端与前端。测试使用隔离 H2 数据库，不修改真实成绩。
