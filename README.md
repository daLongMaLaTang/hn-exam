# 华能山阴培训考试系统

第一阶段建设范围：账号权限、题库、组卷、考试、客观题判卷、成绩统计、补考和错题库。

## 技术栈

- 前端：Vue 3、TypeScript、Vite
- 后端：Java 17、Spring Boot 3
- 数据库：本机演示默认使用 H2，联调和公网部署使用 MySQL 8
- 缓存：Redis 7（账号权限缓存、JWT 状态校验和登录防刷；答卷始终持久化到 MySQL）

## 已完成功能

- 管理员端：人员资料、账号状态、角色权限、自定义身份、密码重置和操作记录
- 题库：按课程和章节分类、单题录入与编辑、批量归章、审核启停、筛选、Excel/CSV/JSON 批量导入、源 Word 题库首次同步
- 组卷与考试：考试绑定课程和章节范围、同范围手工选题、按题型随机抽题、个人考试错题卷、草稿、发布、关闭、考试时段、补考次数和基础切屏记录
- 考生端：按课程刷题、日常错题复练、考试错题复盘、考试倒计时、自动保存、断线续考、自动交卷和成绩解析；日常错题连续答对两次后移出
- 判卷与统计：客观题自动判卷、主观题人工判卷、成绩分布、高错误率题目图表、成绩明细及考试分析 CSV 报表
- 数据保护：已发布试卷保存题目和答案快照；考试中不通过刷题接口泄露答案；角色或账号状态变更立即生效
- 从人员表初始化 114 名考生，临时工号为 `0001` 至 `0114`
- 默认考试规则：100 分、90 分钟、90 分及格，具体考试可单独配置

## 本地启动

当前正式站点已部署到 `https://hqhexam.cn`。本服务器使用宝塔 Nginx、MySQL、Redis 和 systemd，配置及运维说明见 [宝塔部署说明](deploy/baota/README.md)。线上新数据以服务器数据库为准；不要用本机旧快照覆盖后续线上记录。

首次运行先执行 `init-local-infrastructure.ps1`。它会启动 Docker、生成仅供本机使用的 Redis/JWT 随机密钥，并启动持久化 Redis 7；密钥保存在已被忽略的 `.env.local`，不会进入代码库。

之后最简单的方式是在 IDEA 顶部选择“本地完整系统”运行配置并点击运行。也可以双击 `start-local.ps1`，脚本会自动确认 Redis 已就绪，再启动前后端并检查状态。

手工启动后端：

```powershell
$env:JAVA_HOME='E:\web\jdk17\jdk-17.0.20.1+1'
$env:Path="$env:JAVA_HOME\bin;D:\web\maven\bin;$env:Path"
cd E:\hnExam\backend
mvn -Dmaven.repo.local=D:\web\maven-repo spring-boot:run
```

另开一个窗口启动前端：

```powershell
cd E:\hnExam\frontend
D:\web\nodejs\npm.cmd run dev
```

访问 `http://127.0.0.1:5173`。启动日志位于 `E:\hnExam\logs`。

本机演示管理员账号为 `admin`，初始密码为 `Admin@12345`（可通过 `HNEXAM_BOOTSTRAP_PASSWORD` 配置）。所有初始账号均要求首次登录后修改密码。

管理员在“人员与权限”新增考生或 Excel 导入新学员后，会得到每个账号独立的随机初始密码。请在“领取初始密码”区域复制登录信息，或下载 Excel 密码分发清单；密码默认隐藏，关闭或刷新页面后无法重新查询。清单包含密码，请单独分发给对应学员并妥善保管。导入更新已有工号不会修改密码，也不会再次生成密码清单。遗失时由系统管理员在人员列表“重置密码”，确认后领取新的随机密码，原密码和已有登录立即失效；本人改密使用“账号设置”。

既有账号密码不会因本次更新改变。历史 `bootstrap/candidates.csv` 启动导入默认关闭，后续新增请使用上述页面流程；仅在明确兼容旧流程时可设置 `HNEXAM_IMPORT_LEGACY_CANDIDATES=true`，该旧路径仍使用 `HNEXAM_CANDIDATE_PASSWORD` 统一密码，不具备随机密码领取功能。

首次启动会读取提供的安规 Word 题库；结构明确的客观题可直接练习和组卷，填空题、简答题及格式存在歧义的题进入待审核。重复启动只补充尚未导入的题目，不会重复写入。

## 多课程与 Excel 题库导入

“安全规程”只是一个课程题库。管理员可以继续建立“流体力学”“泵与风机”等课程：进入“题库管理 → 批量导入题库”，下载系统 Excel 模板，在每一行的“课程”和“章节”列填写所属范围，再选择文件导入。模板支持单选题、多选题、判断题、填空题和简答题；选择题可填写 A～F 选项，答案可填写字母。单次最多 2000 道，文件最大 5MB，仅支持 `.xlsx`。

导入时系统会逐行校验。正确行直接保存，错误行显示行号和原因，便于修改后再次导入。导入后的题目默认进入待审核，管理员确认并启用后才能用于刷题和组卷。

创建考试时必须先选择课程，可继续选择一个或多个章节作为考试范围；普通试卷从范围内选择已启用题目。选择“个人考试错题卷”后，发布时会按每位启用学员尚未掌握的考试错题生成独立固定试卷，没有符合范围错题的学员不会收到该考试。考生刷题页面也可以按课程和题型筛选。

公网部署前应使用 `application-mysql.yml` 并通过环境变量设置数据库连接、初始密码和 JWT 密钥；云服务器还需配置 HTTPS、定期备份和访问日志。

## Redis、JWT 与 2000 人在考验证

- 登录成功后由后端签发 HS256 JWT，接口通过 `Authorization: Bearer <token>` 校验；令牌包含有效期和账号版本。账号停用、改工号、重置密码后，旧令牌自动失效。密码使用 BCrypt 强哈希保存。
- Redis 缓存当前账号状态和实时权限，减少每次自动保存时查询数据库；连续登录失败默认达到 8 次后限制 15 分钟。Redis 故障时系统自动回退到 30 秒本机缓存，不影响答卷保存。
- 考试答案、成绩和试卷快照不放在 Redis，始终以 MySQL 为准。Redis 重启不会丢失考生答案。
- 考试答案定时上传改为每60秒一次，首次上传随机分散到一分钟内；本机草稿、切屏和交卷仍即时处理。保留无修改时的同步，以检查考试是否取消。连接池默认5～30条连接、等待上限10秒，Tomcat工作线程上限250；这些配置不是可承载考生人数的保证。
- 到期任务只分批查询待处理答卷，每份独立事务，加锁后再次检查是否已交卷；失败不回滚其他答卷，并在后续扫描重试。
- 常规测试保留200个账号、40个工作线程的业务回归。另有显式开启的 `ExamHttpLoadTest`：2000份在考答卷、每份50题、每分钟错峰保存、集中提交、逐题回读及2000份集中到期，最多100个HTTP请求同时执行。使用隔离H2数据库，密码登录/真实浏览器/完整考试时长不在该测试范围。详见 [并发验证说明](../jiaojie/hnExam/归档_2026-10-18/deploy/并发验证说明.md)；正式上线仍须在目标云服务器和MySQL上复测。

本机执行 `init-local-infrastructure.ps1` 后会启用 Redis；使用 MySQL 生产配置时也默认启用。可运行 `check-local-infrastructure.ps1` 查看 Docker 版本、Redis 健康状态和监听地址。服务器需要设置：

```text
HNEXAM_REDIS_ENABLED=true
HNEXAM_REDIS_HOST=127.0.0.1
HNEXAM_REDIS_PORT=6379
HNEXAM_REDIS_PASSWORD=一段单独生成的强密码
HNEXAM_JWT_SECRET=至少32字节且单独生成的随机密钥
```

服务器装有 Docker 时，可以使用 `deploy/docker-compose.redis.yml` 启动仅监听本机地址的 Redis；密码必须放在服务器环境文件中，不要写进代码或提交到版本库。本机 Redis 数据保存在 Docker 命名卷中，重启 Docker 或电脑后不会丢失。
