# v1.3 发布说明 · 2026-11-04
上线站点 https://hqhexam.cn ，北京时间 00:30 完成切换。

1. 简答判卷点击“确认此分”后，服务端成功写入即更新当前作答、解锁按钮。移除服务端多余的整场答卷查询，判卷页空闲时每20秒刷新一次，有待处理任务时每4秒刷新。实际等待时间仍取决于网络和提交请求，未进行生产成绩写入测速。
2. 简答题集中判卷区增加“一键应用AI建议分”。本场考试须有“AI一键判卷”任务记录，未执行时点击会提示“请先AI一键判卷”。确认框列出本次将应用的数量，跨题目和分页，每次最多1000份。只采用当前可安全应用的建议，疑难、过期和已确认作答跳过，成绩仍按原流程统一公布。
3. 创建统一试卷时可填写新的课程名称并上传 PDF、PNG、JPEG，也可拖入计算题图片。每次新增文件合计最多6 MB。每个文件对应一道人工评分题，可设置标题和分值。若希望按题给分，可把各题作为单独图片上传。整卷 PDF 作为一个作答框，考生可下载原卷。图片显示在答题和阅卷页。上传文件随试卷保存，不列入公共题库。
4. 题库管理每行“操作”增加“删除”。系统管理员、培训管理员可以按编号和题干确认删除单题。已发布试卷及历史成绩保留；含被删除题目的未发布草稿需重新选题。
