# v1.4 学员忘记密码 · 发布说明

2026-11-04 00:40（北京时间）上线。学员在登录页选择“忘记密码”，填写工号和档案姓名。系统对外统一提示已收到，匹配在用的普通学员后创建待审记录，同一学员的重复提交只保留一条待审申请。申请期间可使用原密码。

系统管理员进入“人员与权限 → 密码重置申请”，可刷新列表，核对申请时间、部门、姓名和工号，通过已有联系方式或当面核实本人。“通过并重置”生成随机临时密码，由管理员通过已有领取流程单独交给学员。通过后旧密码及旧登录失效，首次登录须修改密码。“驳回”保留原密码。审核结果、经办人、时间记入数据库。权限或登录版本变更导致申请失效时，管理员可驳回并让学员重提。

前端16项测试通过，生产构建通过。后端196项测试，195通过，1跳过。隔离接口测试覆盖去重、普通学员越权被拒、驳回保留密码、通过后变更凭据，以及重复审核被拒。线上入口、版本和静态资源已与构建包比较。随机虚构工号提交得到统一响应，匿名访问审核列表返回401。真实学员的审批与临时密码交付由管理员执行。
